# Tela ao Vivo

Compartilhe a tela do jogo com áudio direto pelo navegador, sem configurar porta nem firewall.

- Quem transmite: **Compartilhar minha tela** → escolhe o áudio do jogo → **Começar** → aba "Tela inteira" → manda o código.
- Quem assiste: **Assistir** → digita o código.

Atalhos no player: `F` tela cheia · `M` mudo · `↑↓` volume · `S` estatísticas · `P` janela flutuante.

Feito em uma página só (`index.html`), com WebRTC + PeerJS. Funciona no Chrome e no Edge.
